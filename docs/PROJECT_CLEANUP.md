## 🏁 **Como Usar**

### Desenvolvimento:
```bash

./start-dev.sh         # Linux/Mac
start-dev.bat          # Windows

# Método 2: NPM
npm run dev            # Frontend + Backend
npm run dev:frontend   # Apenas Frontend
npm run dev:backend    # Apenas Backend
```

### Produção:
```bash
npm run build          # Build otimizado
npm start             # Produção
```
